# 🇰🇷 SEOUL BUY Bách Hóa - Responsive Hero Banner

Một thiết kế Banner HTML5/CSS3 Responsive dành cho cửa hàng tiện lợi Hàn Quốc **SEOUL BUY Bách Hóa**, giới thiệu các tuyệt phẩm bánh kẹo & snack Lotte bán chạy nhất trên Coupang (*Kẹo Caramel Sữa Lotte, Kẹo Sữa Bông Malang Cow, Snack Doritos Nacho Cheese*).

---

## 🌟 Tính Năng Nổi Bật

- **Thiết kế Minimalist Editorial**: Tối giản, sang trọng, màu sắc thanh lịch không lòe loẹt.
- **Tối ưu Responsive 100%**: Co dãn hoàn hảo trên cả Mobile, Tablet và Desktop (đã khắc phục hoàn toàn lỗi tràn viền trên màn hình nhỏ).
- **Showcase Sản phẩm Tương tác**:
  - Desktop / Tablet: Sân khấu 3D hiển thị nổi bật 3 tuyệt phẩm Lotte.
  - Mobile: Tự động sắp xếp thành hàng 3 sản phẩm gọn gàng, vừa vặn màn hình.
- **Mã Giảm Giá 1-Click**: Tích hợp các chip mã ưu đãi (`LOTTE-HOT15`, `LOTTE-COMBO3000`, `LOTTE-FREESHIP`) cho phép người dùng bấm sao chép mã tức thì với hiệu ứng Toast notification.
- **Dễ Dàng Nhúng Web**: Cung cấp sẵn file `standalone-embed.html` tích hợp sẵn CSS & JS, có thể copy-paste trực tiếp vào bất kỳ website, WordPress, Shopify hoặc Landing Page nào.

---

## 📁 Cấu Trúc Mã Nguồn

```text
seoul-buy-banner/
├── index.html            # Trang Studio trải nghiệm & thử nghiệm màn hình (Mobile/Tablet/Desktop)
├── standalone-embed.html # File HTML độc lập nhúng sẵn CSS/JS (dán trực tiếp vào Web)
├── styles.css            # File CSS thiết kế tối giản, chuẩn Responsive
├── script.js            # JavaScript xử lý sao chép mã ưu đãi & chế độ studio
└── assets/
    └── images/           # Thư mục hình ảnh sản phẩm
        ├── caramel.jpg
        ├── malang-cow.jpg
        └── doritos.png
```

## 🚀 Hướng Dẫn Sử Dụng

1. **Xem thử trực tiếp trên máy tính**:
   Mở file `index.html` bằng trình duyệt web bất kỳ.

2. **Nhúng vào trang web của bạn**:
   Mở file `standalone-embed.html`, sao chép toàn bộ mã và dán vào phần HTML/Embed của trang web hoặc WordPress.
